# LegalSearch 1.1.0 RC2 (release candidate) — DRAFT

> **Draft release notes. Not published.**

LegalSearch is **local semantic search for legal PDFs**. Open a PDF in Google Chrome, describe what you are looking
for in your own words, and LegalSearch shows the passages that mean that — even when the document uses different
words — with their page number and a **Go to page** button.

> LegalSearch is a document retrieval tool. It does not provide legal advice, determine legal conclusions, or replace
> professional legal analysis.

## Status

This is a **release candidate** intended for testing with lawyers before a stable 1.1.0. Retrieval and ranking are
unchanged from RC1; RC2 adds public-release documentation, license notices in the installer, CI and a privacy fix in
the engine log. See [CHANGELOG.md](../../CHANGELOG.md).

**Supported platform**: Windows 10/11 x64 with Google Chrome (116 or later).

## What it does

- **Semantic search**: queries and passages are compared by meaning using multilingual embeddings
  (multilingual-e5-small). It is not keyword matching; it works across paraphrases and different wording.
- **Page-aware results**: each result shows its page; **Go to page** opens the PDF at that page.
- **Web and local PDFs**, in Chrome's own PDF viewer.
- **Fast after the first time**: a document is prepared once (about 2 seconds per 100 pages) and cached locally;
  searches take a few milliseconds.

## Private by design

- PDFs, queries and embeddings are processed **on your computer**. Nothing is uploaded.
- No cloud processing, no external AI APIs, no accounts, no telemetry, no analytics.
- Details: [PRIVACY.md](../../PRIVACY.md).

## Installation

1. Download `LegalSearchSetup.exe` and `SHA256SUMS.txt` and verify the installer (see below).
2. Run `LegalSearchSetup.exe` → **Next** → **Install** → **Finish**. No administrator rights are required.
3. **The Chrome extension must currently be loaded manually** (it is not yet in the Chrome Web Store). The guide that
   opens after installation walks through it:
   `chrome://extensions` → **Developer mode** → **Load unpacked** → `%LOCALAPPDATA%\LegalSearch\extension`, then
   **Details** → **Allow access to file URLs** (for PDFs saved on the computer).

`legalsearch-extension-store.zip` is the package prepared for a future Chrome Web Store submission; end users do not
need it.

## Optional feedback for search quality

Each result has **Relevant** / **Not relevant** buttons, and **Missing result?** records where the expected passage
actually was. Feedback is stored only in your Chrome profile. **Export evaluation data** saves a JSON file you can
choose to share with the developers. The export contains your queries and short excerpts (up to 300 characters) of
the judged passages — review it before sharing confidential material. See the
[tester guide](../tester-guide.md).

## Experimental hybrid retrieval (off by default)

A hybrid mode that fuses semantic retrieval with BM25 keyword statistics (Reciprocal Rank Fusion) is included for
evaluation only. It is **disabled by default** and is enabled only by setting the environment variable
`LEGALSEARCH_HYBRID=1`. Default search is semantic (dense) only.

## Known limitations

- **Unsigned binaries**: the installer and engine are not code-signed. Windows SmartScreen shows "Windows protected
  your PC" (**More info → Run anyway**), and Windows 11 **Smart App Control**, when enforced, may block the engine; in
  that case the side panel reports that the local engine is not installed. See
  [docs/code-signing.md](../code-signing.md).
- **Scanned PDFs** (images without a text layer) are detected but not supported: they need OCR first.
  Password-protected PDFs cannot be read.
- **Go to page** reloads the PDF tab (Chrome's viewer applies `#page=N` only on load), so the zoom level resets.
- Windows and Google Chrome only.
- Retrieval quality has been measured on small evaluation sets; real-world feedback is being collected.

## Verify your download (SHA-256)

PowerShell:

```powershell
Get-FileHash .\LegalSearchSetup.exe -Algorithm SHA256
Get-FileHash .\legalsearch-extension-store.zip -Algorithm SHA256
```

or, with `SHA256SUMS.txt` in the same folder (Git Bash, WSL, Linux, macOS):

```bash
sha256sum -c SHA256SUMS.txt
```

The values must match exactly:

```text
ceb02a02d7fa6052a7dda5bcd6c941ea9419b48f23c4ac1206548d3ea7b08ea1  LegalSearchSetup.exe
da48b283cae7c833fcd78ff02370ba3b415b00b80348baa822bf6a2fd6ed84ac  legalsearch-extension-store.zip
```

(These are the hashes of the locally built RC2 artifacts. If the release is rebuilt by the release workflow, publish
the hashes from that build's `SHA256SUMS.txt` instead.)
