Turn on LegalSearch in Google Chrome

The program is installed. One last step remains, and you only do it once.

  1. Open the LegalSearch page in the Chrome Web Store: install the extension.
  2. Click Add to Chrome.
  3. If you work with PDFs saved on your computer: in chrome://extensions, open LegalSearch's Details and turn on Allow access to file URLs.
  1. In Chrome, type chrome://extensions in the address bar and press Enter.
  2. Turn on Developer mode (switch in the top-right corner).
  3. Click Load unpacked and choose this folder:
    {{EXTENSION_PATH}}
    You can paste the path into the top bar of the folder picker.
  4. On the LegalSearch card, click Details and turn on Allow access to file URLs.
    Needed to search PDFs saved on your computer.
  5. Click Chrome's puzzle-piece icon and pin LegalSearch.

Everyday use

Open a PDF in Chrome, click the LegalSearch icon and type what you are looking for in your own words. The first time you open a document it takes a few seconds to prepare; after that it is ready instantly.

Local processing. The document never leaves this computer. LegalSearch does not use the Internet, has no accounts and sends no data to anyone.

Uninstall

Windows Settings → Apps → LegalSearch → Uninstall. Remove the extension in chrome://extensions → Remove.
